# 企業健檢／陪跑系統收工交接

更新日期：2026-10-10

## 已完成

1. 健檢問卷標準底稿已更新逐月營運資料欄位：應收帳款、應付帳款、存貨、新客戶、流失客戶。
2. 健檢系統 v3 標準底稿已接收問卷的月度資料，並可供陪跑模板讀取。
3. 陪跑訂閱模板已具備月度來源、月度儀表板、自動覆核與行動計畫。
4. 舊版問卷標準底稿已保留在 Google Drive，名稱為 `健檢問卷_標準底稿_舊版_20261003`。

## 使用步驟

1. 為客戶複製健檢問卷與健檢系統標準底稿。
2. 在客戶健檢系統的資料匯入頁連結客戶問卷，並允許 `IMPORTRANGE`。
3. 為客戶複製陪跑訂閱模板，在 `Control` 頁貼入客戶健檢系統網址，並允許存取。
4. 顧問依 `Auto Review` 與 `Action Plan` 進行月度回顧；客戶只需持續更新問卷的月度資料。

## 注意事項

- `跑健檢_匯入客戶問卷.bat` 是舊版本機匯入工具，尚未支援新版 A:M 月度欄位；不要作為現行流程。
- 此 GitHub 專案只保存可公開程式與文件，不納入客戶資料、Google 認證檔或服務帳戶資料。
